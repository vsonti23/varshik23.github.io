Venom

Designed a Programming Language called Venom using Python and Prolog. Venom is a statically typed, object-oriented, and imperative programming language. It supports the following features: variables, functions, classes, objects, inheritance, and polymorphism. The language also supports the following data types: int, float, string, boolean, and list. The language is implemented using Python and Prolog. The parser is implemented using PLY (Python Lex-Yacc). The language is compiled using Prolog. The compiler generates the intermediate code in the form of a list of instructions. The interpreter is implemented using Prolog. The interpreter executes the intermediate code generated by the compiler. The language is tested using unit tests and integration tests.
